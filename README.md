# SoftwareDesignProject
github repo for MATLAB SDP for ENGR 1181

3 people for initial game mode
endless(maybe? might take too much)

functions:
walking
picking up foods/prompt that comes up with that
defining the requirements for the person
checking the requirements meet the food that we have picked up
manual part that can be clicked to show what certain things mean (definition of vegan, vegetarian, pescetarian, etc)
timer that gives points based on how accurate you meet the parameters and the amount of time you take (definitely can be omitted if need be)
final score screen
